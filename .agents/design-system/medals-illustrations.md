# Illustrations & Stickers

Figma: https://www.figma.com/design/1ibE2wPPDAauJKaj1ft6AC/Design-System

## Role split（三类资产）

| 类型 | 形态 | 目的 | 状态 |
|------|------|------|------|
| **Scene Illustration** | 平面、高对比、模拟真实物体场景 | 吸引点击，引导进入使用场景 | **Active** · `15 · Illustrations` |
| **Sticker** | 平面图形，外形多样（圆章/横幅/票根/胶囊） | 激励尝试新特性 / 小阶段达标奖励 | **Active** · `16 · Stickers` |
| **Medal** | **3D 资产**（非平面） | 成就体系 | **Deferred** · `14 · Medals` 仅占位 |

---

## Scene Illustrations · 场景插画

**规则**
- 平面色块，**色彩对比强**（珊瑚 / 天蓝 / 薄荷 / 日光黄 / 深蓝）
- 模拟真实世界物体（手机、水瓶、跑鞋、床、手表充电座等）
- 一眼能认出场景；下方 CTA 指向 Tab / 流程入口

| Scene | Props | 引导去向 |
|-------|-------|----------|
| **Morning desk** | 窗光、手机、水瓶、耳机盒 | → Today |
| **Ready to move** | 跑道、跑鞋、毛巾、水壶 | → Exercise START |
| **Wind-down night** | 床、枕头、台灯、床头手表 | → Health sleep |
| **Link your watch** | 充电座、手表、手机、连接点 | → Devices pair |

Deep link: https://www.figma.com/design/1ibE2wPPDAauJKaj1ft6AC/Design-System?node-id=22-4

## Stickers · 贴纸

**规则**
- 纯平面；白描边 + 轻硬投影（贴纸感）
- 外形可多样：圆章、横幅、票根、胶囊、圆角方章
- **不是勋章**；用于轻量激励与新特性试用

| Sticker | 激励场景 |
|---------|----------|
| `NewFeature` | 尝试新特性 |
| `FirstStart` | 首次开练 |
| `SleepTried` | 打开睡眠洞察 |
| `DevicePaired` | 完成设备配对 |
| `Day3` | 连续 3 天活跃 |
| `Hydration` | 尝试喝水提示 |
| `EarlyBird` | 早间打开 App |
| `Insight` | 查看健康洞察 |

Deep link: https://www.figma.com/design/1ibE2wPPDAauJKaj1ft6AC/Design-System?node-id=29-2
