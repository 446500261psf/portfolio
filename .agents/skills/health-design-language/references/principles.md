# Principles · HeartLine design worldview

Derived from the locked ribbon-heart mark. Use as the filter for every design decision.

## Brand feeling

| Soft | Hard (avoid as default) |
|------|-------------------------|
| Continuous, flowing, alive | Fragmented, sticker collage |
| Soft geometric, rounded | Sharp industrial / brutalist spikes |
| Calm confidence | Loud neon / esports glare |
| Folded depth, tactile | Flat sticker with fake chrome |
| Health + motion in one line | Clinical cold OR toy cartoon |

One-line promise: **One line. Every heartbeat.**

## Form language

Inherit from the mark’s geometry:

- **Circle + arc** as primary primitives (left loop is a perfect circle)
- **Even thick stroke** as the hero weight language (icons/lines should feel related)
- **Diagonal fold / tip** allowed as a single sharp accent — not everywhere
- **Negative space** (the loop hole) is part of the identity — preserve breathing room

## Depth language

The mark teaches how we do “3D”:

- Depth = **local overlap**, not environment lighting
- Soft gradient or soft contact shadow **only where ribbons cross**
- Optional long soft ground shadow for splash floating moments
- Forbidden as system default: multi-stop specular gloss, colored outer glow, skeuomorphic bevel

## Hierarchy

1. Brand mark / product name (hero when on branded surfaces)
2. One headline
3. One short support line
4. One CTA group
5. Everything else waits for the next section

On branded first viewports: the HeartLine mark (or wordmark lockup) must remain a hero-level signal — not a tiny nav favicon after you remove the chrome.

## Density

- Prefer **one composition**, one job per section
- Cards only when they contain a real interaction; never card-ify the logo hero
- Illustration: 1 subject + 2–3 supports (see `health-illustration`)
- Icons: single metaphor, no mini-illustrations inside 24px

## Voice in visuals

- Trustworthy companion, not hospital
- Active living, not gym-bro aggression
- AI+ moments may use violet bridge `#7A6FD1` — sparingly, never replacing brand orange as the identity color
