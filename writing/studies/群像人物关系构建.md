# 群像文：怎么构建人物关系

> 群像难在「人多却不散」。关系不是配角说明书，而是**让 A 的选择必然牵动 B、并留下可继承余波**的结构。

---

## 0. 先纠正一个误区

群像文的关系，不是：

- 把所有人两两拉条线（会炸）
- 每人一段独立身世（会散）
- 主角光环辐射一圈「队友」（那是小队文，不是群像）

而是：

**少数「承重关系」+ 多数「功能关系」+ 可交接的「余波关系」。**

每卷/每代，读者真正要记住的关系，通常不超过 **3 条承重边**。

---

## 1. 玄鉴式群像的关系逻辑（可迁移）

《玄鉴仙族》看起来人很多，骨架其实是：

1. **共同体中心**（李家）不是一个人，是「家」这个容器  
2. **每代 2–3 个记忆点角色**，互相有分工（决策 / 武力 / 经营 / 书写）  
3. **死亡不是删号，是改关系网**：死的人把义务、仇、规矩、名声传给下一个人  
4. **幕后者（鉴）不抢戏**：他提供条件，关系仍在台前人之间结算  

所以群像关系的第一问不是「谁喜欢谁」，而是：

> 这个共同体里，**谁欠谁、谁护谁、谁代表规则、谁会被牺牲、牺牲后账记在谁身上？**

---

## 2. 关系的四种承重类型（先定类型，再写感情）

搭群像时，先给每条重要关系贴一个「结构标签」：

| 类型 | 问题 | 例子 |
|---|---|---|
| **资源关系** | 谁供谁粮/刀/情报/名额？断裂会怎样？ | 驿长供刀手活路；刀手供出援 |
| **规则关系** | 谁代表家规/约法？谁被迫违规？ | 沈砺=必援；签弃援合同时关系裂 |
| **见证关系** | 谁替谁「被记得」？谁掌握书写权？ | 沈禾点名；闵老师点名；半夏贴海报 |
| **镜像关系** | 两人面对同一压力的相反选择 | 康叔用身体证明还在 / 中介用系统证明不在 |

感情（亲、仇、暧昧、师徒）是表层涂料；**缺了上面四种结构，感情会空。**

一句话检验：

> 删掉这条关系，主线还会不会少一次「不得不选」？  
> 不会少 → 这条关系只是装饰，降级为功能边。

---

## 3. 三角是最小群像单元（比双人稳）

双人关系容易写成拉扯独角戏。群像最小稳定单元是**功能三角**：

```
        决策者
       /      \
   代价者 —— 书写者/见证者
```

### 现代例（《夜校清单》）

| 角 | 人物 | 功能 |
|---|---|---|
| 决策者 | 闵老师 | 守约法、拒卖名单、砸平板 |
| 代价者 | 康叔 | 用身体证明「还在」，死揭棋盘 |
| 书写者 | 半夏 | 从被写到改写，把真名贴出去 |

三角内部至少要有一次：

1. **结盟**（共同拒中介）  
2. **分歧**（认证与否 / 要不要去挡清楼）  
3. **交接**（康叔死后，半夏继承「写还在」）

没有交接，群像会死一人掉一摊；有交接，死人才变成结构零件。

### 古典例（《盐骨十驿》）

| 角 | 人物 | 功能 |
|---|---|---|
| 决策者 | 沈砺 | 哨响必援、签合同 |
| 代价者 | 麻子柒 | 信哨出援而死 |
| 书写者 | 沈禾 | 朱砂点名 → 唱名夺权 |

## 4. 关系网怎么画（实用画法）

### 4.1 只画「本卷三焦点」

不要一上来画二十人。先画：

```
A ——(欠/护/违)—— B
 \                 /
  \---- C --------/
```

每条边写 **动词**，不写形容词：

- 坏：`沈砺 与 麻子柒 感情好`  
- 好：`沈砺 拖欠 抚恤却仍派 麻子柒出援；麻子柒 用命换 被沈禾点名`

### 4.2 边的强度三级

| 级 | 含义 | 写法 |
|---|---|---|
| 承重边 | 断了主线变形 | 每卷必有场景兑现 |
| 功能边 | 推动一次情节 | 出场即办事，不强行加戏 |
| 余波边 | 人死后仍作用 | 遗物、规矩、名字、仇恨、欠账 |

群像高级技巧：**把承重边在死后改成余波边**，而不是直接删除。

### 4.3 关系卡模板（两人一张，比一人一张更重要）

```md
# A × B

- 结构类型：资源 / 规则 / 见证 / 镜像（可多选，主选一个）
- 公开关系：
- 私下真相：
- 互相欠什么：
- 第一次裂缝（事件）：
- 不得不选的场景（本卷）：
- 若 A 死，B 继承什么：
- 若 B 死，A 继承什么：
```

人物卡写「他是谁」；关系卡写「他们迫使彼此成为谁」。

## 5. 群像关系的时间设计：接力，不平行

平行群像（每人一条线同时推）最易散。更稳的是**接力**：

```
阶段1：A-B 结盟建立体温
阶段2：B 死/退 → 关系账转给 C
阶段3：C 用继承物对抗制度
阶段4：新三角形成（C + D + E）
```

《玄鉴》的代际感，本质就是关系接力：  
上一代的牺牲，变成下一代的规矩、仇、或忌讳。

检查表：

- [ ] 每个退场角色至少留下 1 样「可继承物」（名/债/规矩/技能/仇）  
- [ ] 继承人接的不是人设，是**未完成的选择**  
- [ ] 新角色入场，必须先挂上旧债，再展示个性  

---

## 6. 冲突不靠吵架，靠「同一资源的相反用法」

群像最假的关系冲突：开会对骂。  
更真的冲突：

| 资源 | A 用法 | B 用法 |
|---|---|---|
| 名单 | 闵：绝不卖 | 中介：买来拆 |
| 骨哨 | 沈砺：信了就援 | 沈禾：太清楚就别信 |
| 身体 | 康叔：挡门证明还在 | 系统：合户证明不在 |
| 合同 | 沈砺：买时间 | 沈禾：卖了必援 |

关系戏的高潮，是两人必须对同一资源做相反决定，且**两边都有理**。

## 7. 七步搭一张群像关系网（可照做）

1. **定共同体容器**（家/夜校/驿/船坞）  
2. **定本卷三焦点**（决策者、代价者、书写者——可换名，功能别缺）  
3. **画三角三条承重边**（每条用动词）  
4. **给每人一个「关系伤口」**（不是独自伤口，是对某人做错过/欠过）  
5. **设计一次分歧场景**（同资源反用法）  
6. **设计一次交接**（死/走/失能 → 余波边）  
7. **再加功能角色**（官差、中介、盟友），只连一条边，禁止人人互连  

做完这七步，再写对话。对话会自然有摩擦力。

---

## 8. 反模式（群像关系常见翻车）

| 翻车 | 原因 | 改法 |
|---|---|---|
| 人多但谁死都一样痛 | 没有独特欠账 | 每人只欠一个具体的人 |
| 全员忠诚一家人 | 无内部分歧 | 加「同资源反用法」 |
| 新角色空降抢戏 | 未挂旧债 | 先继承再闪光 |
| 关系靠表白/独白说明 | 没有共同行动 | 改成一起扛一次事 |
| 死后只哭一场 | 无余波边 | 留下名/债/规矩继续推动剧情 |

## 9. 最小练习（30 分钟）

任选你的故事，只填这张表：

| 角色 | 本卷功能 | 最欠谁 | 最怕对不起谁 | 死后留给谁什么 |
|---|---|---|---|---|
|  | 决策者 |  |  |  |
|  | 代价者 |  |  |  |
|  | 书写者 |  |  |  |

填得出来，群像关系就立了；填不出来，先别加人。
