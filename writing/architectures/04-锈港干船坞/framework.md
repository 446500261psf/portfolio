# 《锈港干船坞》整体故事框架

> 读这一份就能把握全书骨架。人物细卡见 `characters/`。

---

## 1. 故事是什么

废弃干船坞。中枢残核「回声芯」会断续唤醒旧船记忆：有时指出裂缝救人，有时把活人认成已拆构件。  
轨道拆船集团按吨收购废料；港口管理局用安全令清场。韩氏工人世家与外雇潜水员要争夺的，不是舰队荣耀，是**谁有权宣布一条船、一群人、一座港该死（报废）**。

**不是**：舰长开挂复国。  
**而是**：劳动家族对抗合法报废；芯给过图纸，也当过死刑开关。

---

## 2. 核心引擎

| 柱 | 内容 |
|---|---|
| 鉴 | 回声芯：可回放应力；过热/远程补丁会把人标成构件 |
| 压力机 | 拆船吨位收购 + 安全令驱人 + 保险只赔已报废资产 |
| 共同体 | 工坊契：活人不入库、报废须三人目击、外雇同工同酬 |
| 揭棋盘之死 | 虫牙被芯误标「可切割构件」，远程臂启动杀死他 |
| 制度过时 | 契被《资产快速报废通道》架空；合作社牌照仍被吞 |
| 终局 | **半成功**：坞爆，但误杀黑匣公审成立，工卡成证词 |

---

## 3. 四卷故事线

```
卷一 求生           卷二 揭棋盘         卷三 制度升级        卷四 抗命数
偷电修船/同工同酬 → 虫牙误杀追补丁 → 合作社vs报废通道 → 安全诱饵爆破+公审
```

### 卷一 · 求生

1. 断电令；芯短暂醒来指出船缝，换来活命单。  
2. 虫牙加入；争同工同酬引发老工人争执。  
3. **卷末**：芯把虫牙标成构件 → 切割臂启动 → 死。  
4. **失灵**：生命体征被读成震动噪声。

### 卷二 · 揭棋盘

1. 远程补丁签名、报废通道、保险条款三联曝光。  
2. 韩荻从巡检变成取证者。  
3. 明线从「修船」变成「追谁有权按下水」。

### 卷三 · 制度升级

1. 工坊改制文化遗产合作社，仍进快速报废流程。  
2. 韩铁锈签「分期撤离」换暂时供电——违契。  
3. 合法外衣越来越像屠宰证。

### 卷四 · 抗命数

1. 芯确认结构安全 → 实为安全令诱饵，爆破提前。  
2. **大失灵**：信任芯的安全判定，人几乎被埋。  
3. 变数：误杀日志做成黑匣公审。  
4. 半成功：坞没了，报废神话裂了。

## 4. 人物位置

| 人物 | 职能 | 弧线 |
|---|---|---|
| 韩铁锈 | 决策 / 契的活体 | 曾赶工害死学徒 → 拒活人入库 → 可为公审壮烈 |
| 韩荻 | 取证视角 | 信芯 → 知芯可劫持 → 黑匣出品人 |
| 虫牙 | 揭棋盘之死 | 用身体换同酬先例 → 被标构件 → 打开死刑链 |

---

## 5. 明暗线

- **明线**：偷电求生 → 误杀追责 → 改制屈辱 → 公审  
- **暗线**：安全令清场、报废通道、回声芯补丁=远程开关  

每次芯说话都问：船的记忆，还是资本的补丁？

---

## 6. 节奏曲线

```
锈与汗的日常 → 芯立一功 → 人被当零件切死 → 合同吃人 → 安全诱饵 → 公审余烬
```
