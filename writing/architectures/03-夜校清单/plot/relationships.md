# 《夜校清单》关系网（示范）

本卷三焦点三角：

```text
          闵老师（决策/约法）
           /              \
     拒卖名单·砸平板      煮面留人·教「还在」
         /                  \
   康叔（代价/身体） ——交接真名—— 半夏（书写/改写）
         \                  /
          挡门·「这楼还有人」
```

## 承重边

### 闵老师 × 康叔（规则 + 镜像）

- 公开：师生/楼内同盟  
- 真相：闵曾卖过名单；康在系统里「已不在」却守灯  
- 欠：闵欠「不再用名单伤人」；康欠楼里一个被承认的位置  
- 裂缝：认证学习点会把康变成「滞留」  
- 不得不选：康要去挡清楼，闵想留他  
- 康死后闵继承：拒认证吃人 + 把「还在」当课

### 闵老师 × 半夏（见证 + 资源）

- 公开：师生  
- 真相：闵把半夏当「可被系统改写的人」的活样本；半夏把闵当最后一张桌子  
- 欠：簿子救半夏一命；半夏用短句把夜校写回街上  
- 裂缝：信「出勤·安全」导致半夏车祸  
- 交接：半夏从被写 → 替康叔应「到」→ 组织贴真名

### 康叔 × 半夏（见证）

- 公开：门房与学员  
- 真相：都怕被写成空  
- 康嘱半夏撕掉头盔上的「迁」  
- 康死后半夏继承：短句钉名（康建平。还在。）

## 功能边（不建卡）

- 中介 → 闵：买名单（一次冲突即可）  
- 旧改车 → 康/半夏：物理伤害（制度的牙）  
- 出勤簿 → 三人：受限好运，不占人物席

## 接力时序

1. 闵-半夏因「缺勤」预警建立信任  
2. 三人共同拒卖名单（三角结盟）  
3. 康死，「已迁」揭棋盘；半夏接管书写  
4. 闵砸平板；半夏贴海报；桥下续课（新日常三角：闵+半夏+缺席的康）
