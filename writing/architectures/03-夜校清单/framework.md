# 《夜校清单》整体故事框架

> 读这一份就能把握全书骨架。人物细卡见 `characters/`。

---

## 1. 故事是什么

旧城筒子楼里的夜校。出勤簿会自己改字：有时提前写出明天谁缺勤（像预警），有时把活人改成「已迁」（像处决通知）。  
旧改指挥部用空置率决定铲平；合户能让门房在法律上「先消失」。闵老师、骑手学员乔半夏、门房康叔结成短暂共同体——要守的不是楼，是**名字还由谁来写**。

**不是**：热血教师逆袭改命运。  
**而是**：教育共同体对抗名单暴力；簿子救过人，也坑过人。

---

## 2. 核心引擎

| 柱 | 内容 |
|---|---|
| 鉴 | 出勤簿：预写缺勤/迁出；被扫描进市政后会乱改或罢工 |
| 压力机 | 空置率考核 + 中介买名单 + 取缔非正规聚集 |
| 共同体 | 夜校约法：不卖名单、不赶病员、账目公开 |
| 揭棋盘之死 | 康叔被预写「已迁」，次日死在清楼扬尘里（户籍早已合户删除） |
| 制度过时 | 约法让位于消防/认证/签到 App |
| 终局 | **半成功**：楼仍拆，夜校迁桥下；名单神话裂开 |

---

## 3. 四卷故事线

```
卷一 求生         卷二 揭棋盘        卷三 制度升级       卷四 抗命数
电费/恐吓/拒卖名单 → 康叔「已迁」而死 → 转正考核/安全夜车祸 → 海报真名+桥下续课
```

### 卷一 · 求生

1. 电费将断；簿子预写半夏缺勤——她避开塌棚（好运成立）。  
2. 中介买名单，闵老师拒。  
3. 康叔用身体挡清楼队。  
4. **卷末**：康叔页出现「已迁」→ 次日真死。  
5. 预写第一次不像警告，像通知。

### 卷二 · 揭棋盘

1. 合户文件、空置率造假、取缔函同日到达。  
2. 半夏开始夜间张贴被删者真名。  
3. 明线从「上课」变成「夺回命名」。

### 卷三 · 制度升级

1. 转正考核：摄像头、签到平板、禁止非学员滞留。  
2. **大失灵**：簿子预报半夏安全 → 安全夜被挂拆迁通行证的车撞。  
3. 闵老师砸平板，保住纸簿。

### 卷四 · 抗命数

1. 算法要删除整栋楼。  
2. 变数：学员把簿子影印成街头海报；簿子拒写「已迁」（罢工）。  
3. 半成功：楼拆，课在桥下继续。

## 4. 人物位置

| 人物 | 职能 | 弧线 |
|---|---|---|
| 闵老师 | 约法活体 | 曾交过可拆名单 → 永久拒卖 → 可为夜校壮烈 |
| 乔半夏 | 从被写到改写 | 被簿子救 → 学会自己写别人的真名 |
| 康叔 | 揭棋盘之死 | 法律上已不在 → 用身体证明还在 → 死 |

---

## 5. 明暗线

- **明线**：续课求生 → 追合户真相 → 抗认证 → 海报/桥下  
- **暗线**：旧改空置率、学教认证清人、簿子=数据裂缝  

每次预写都要追问：预警，还是系统提前执行删除？

## 6. 节奏曲线

```
温热的课堂 → 神迹救人 → 「已迁」杀人 → 造假露齿 → 规范吃人 → 海报夺名（余烬里继续上课）
```
