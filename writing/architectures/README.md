# 故事架构库

按《玄鉴仙族》构书法 skill 生成的**独立完整**长篇结构草案。  
**不绑定** `writing/bible/` 里的雷利亚设定；可任选一套开写。

方法来源：`writing/studies/玄鉴仙族-构书法拆解.md`  
Agent 工作流：`.cursor/skills/novel-architecture/SKILL.md`

## 四套对照

| # | 书名草案 | 题材皮 | 核心不是 / 而是 | 「鉴」 |
|---|---|---|---|---|
| 01 | 《潮汐名册》 | 近未来沿海治水 | 不是天才工程师救世，而是治水家族在保险与市政收割下代际求存 | 失灵的潮汐预测仪 |
| 02 | 《盐骨十驿》 | 边塞盐道群像 | 不是镖局打怪升级，而是驿站血脉在盐引垄断里接力活命 | 时灵时不灵的骨哨 |
| 03 | 《夜校清单》 | 都市拆迁软科幻 | 不是热血教师改变命运，而是夜校共同体在名单逻辑里被逐个结算 | 会改字的出勤簿 |
| 04 | 《锈港干船坞》 | 工业科幻 | 不是舰长开挂复国，而是船坞工人世家对抗拆船资本的「合法报废」 | 半瞎的船坞回声芯 |

每套均含：六问、卷纲、明暗线、死亡政策、3 名锚点人物、2 个势力、结算系统、年表与卷一快照。

## 选用建议

- 想要**家族代际 + 制度**：01 或 02  
- 想要**当代质感 + 名单暴力**：03  
- 想要**劳动史诗 + 科幻器物**：04
