# 四套架构速览（给选题用）

每套都跑完 skill：六问 → 四卷 → 3 锚点 → 2 势力 → 结算系统 → 揭棋盘之死 → 半成功结局。

---

## 01 《潮汐名册》｜近未来治水

- **一句话**：治水家族 vs 保险/市政的「可淹区」收割。  
- **鉴**：听潮匣（可致盲）。  
- **揭棋盘**：外姓临时工阿蟳死于「安全夜」。  
- **主题刺点**：名册把人写成损耗。  
- **适合**：制度感、家族代际、现实主义+轻器物。

## 02 《盐骨十驿》｜边塞盐道

- **一句话**：驿站血脉 vs 盐引垄断与私盐假哨。  
- **鉴**：骨哨（可误/可假）。  
- **揭棋盘**：刀手麻子柒死在空驿。  
- **主题刺点**：书写权——官册 vs 唱词真名。  
- **适合**：古典边塞气质、群像牺牲、民谣对抗文书。

## 03 《夜校清单》｜都市拆迁

- **一句话**：夜校共同体 vs 空置率/合户删除。  
- **鉴**：会改字的出勤簿。  
- **揭棋盘**：门房康叔被预写「已迁」后真死。  
- **主题刺点**：名单即处决。  
- **适合**：当代质感、轻奇幻、教室与街道体温。

## 04 《锈港干船坞》｜工业科幻

- **一句话**：船坞工人世家 vs 「合法报废」资本。  
- **鉴**：回声芯（可被远程补丁劫持）。  
- **揭棋盘**：潜水员虫牙被标成「可切割构件」。  
- **主题刺点**：谁有权宣布人/港报废。  
- **适合**：劳动史诗、科幻器物、公审式终局。

## 共用脊柱（玄鉴方法）

```
受限好运（鉴）
  → 世界压力机先吃人
    → 每卷≤3锚点代际/共同体接力
      → 一场死亡揭棋盘
        → 旧制度过时
          → 抗「可计算命运」
            → 允许半成功
```

详细文件均在对应子目录。选题后从该套 `story.md` + `plot/outline.md` 开写卷一场景节拍即可。
