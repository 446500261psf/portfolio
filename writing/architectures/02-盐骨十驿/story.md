# 《盐骨十驿》

## 一句话

边塞盐道上的「骨哨驿」一族，靠一支时灵时不灵的骨哨传信活命；盐引衙门与私盐盟把驿卒写成路耗，十座驿站像十节被咬的骨头。

## 不是 / 而是

- **不是**：镖头开挂打穿盐政  
- **而是**：驿站血脉在垄断与私盐夹缝里代际接力；骨哨会救命也会害命

## 杂交源

- 纵向：驿路家谱、职役制度  
- 横向：群像可死、边塞残酷、器物微玄

## 调性

干风；咸腥；文书压刀

## 六问

1. **鉴**：祖传骨哨。吹响时可「听」到下一驿是否仍在——但风暴、血污、假哨、吹错调时会误报「仍在」。  
2. **压力机**：官盐配额抽干边民；私盐盟收保护费；驿卒死亡记为「路耗」不记抚恤。  
3. **锚点**：沈砺（本代驿长）、沈禾（妹，记账）、麻子柒（外雇刀手）。  
4. **揭棋盘之死**：麻子柒信骨哨「下驿仍在」独赴救援，撞进已被盐引衙门焚毁的空驿。  
5. **制度**：驿规「哨响必援、假账开革、私盐不进门」。盐道军事化后，驿规被《盐引护送新例》吞掉。  
6. **好运失灵**：卷三沈砺吹哨确认「粮驿安全」，押全家口粮过去——实为盐盟学舌假哨。

## 死亡政策

- 不可死（卷一）：沈禾  
- 可棋子死：麻子柒（卷一末）  
- 可壮烈：沈砺（卷三/四）  
- 可无名死：各驿更夫

## 四卷

1. 求生：守第三驿；私盐与官差两头逼  
2. 揭棋盘：麻子柒之死 → 空驿焚档 → 路耗制度露齿  
3. 制度升级：驿站改商团；驿规变合同  
4. 抗命数：十驿名册已算死沈氏；变数是沈禾把真账写入民谣而非官册
