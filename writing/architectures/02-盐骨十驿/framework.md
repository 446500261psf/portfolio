# 《盐骨十驿》整体故事框架

> 读这一份就能把握全书骨架。人物细卡见 `characters/`。

---

## 1. 故事是什么

边塞盐道「骨哨驿」。沈氏世代传信、护送、记账。祖传骨哨能「听」下一驿是否仍在，但风暴与假哨会骗人。  
盐引衙门把驿卒死亡写成「路耗」；私盐盟收保护费并学舌假哨。十座驿站像十节被咬的骨头——沈家要守的不是盐，是**人名还能不能被写下**。

**不是**：镖头开挂打穿盐政。  
**而是**：驿站血脉在垄断夹缝里接力；书写权比刀更致命。

---

## 2. 核心引擎

| 柱 | 内容 |
|---|---|
| 鉴 | 骨哨：时灵时不灵；可被学舌假哨 |
| 压力机 | 官盐配额 + 私盐保护费 + 路耗抹抚恤 |
| 共同体 | 沈氏驿规：哨响必援、假账开革、私盐不进门 |
| 揭棋盘之死 | 麻子柒信哨出援，死在已被焚毁的空驿 |
| 制度过时 | 驿规被《盐引护送新例》吞掉；驿改商号 |
| 终局 | **半成功**：路还在走，人少一半，真名进了民谣 |

---

## 3. 四卷故事线

```
卷一 求生        卷二 揭棋盘       卷三 制度升级      卷四 抗命数
守第三驿两头逼 → 空驿/路耗露齿 → 改商号/假哨骗粮 → 民谣名册夺书写权
```

### 卷一 · 求生

1. 配额削减；刀手只剩外雇麻子柒愿留。  
2. 一夜两拨叫门：官差要人，私盐要路。  
3. 沈砺守「必援」；沈禾私账记死人。  
4. **卷末**：骨哨报「下驿仍在」→ 麻子柒独赴 → 死于空驿。  
5. **失灵**：哨听到的是风，不是人。

### 卷二 · 揭棋盘

1. 空驿墙根挖出被烧的抚恤名册副本。  
2. 读者明白：路耗 = 合法抹名。  
3. 沈禾改用唱词记死人真名——书写权离开官册。

### 卷三 · 制度升级

1. 驿站挂商号才能领引；沈砺签「可放弃救援」合同（违驿规）。  
2. **大失灵**：假哨确认粮驿安全，全家口粮被骗。  
3. 私盐盟与衙门的默契齿露出来。

### 卷四 · 抗命数

1. 并驿令：十驿改三，沈氏删除。  
2. 变数：民谣名册在边民中传开，官引失去唯一书写权。  
3. 半成功：盐道未光复，但人不能再被无声无息写成路耗。

---

## 4. 人物位置

| 人物 | 职能 | 弧线 |
|---|---|---|
| 沈砺 | 决策 / 必援铁规 | 从救人到被迫签弃援，再为真名付出 |
| 沈禾 | 书写权 | 从私账到唱词，抢走命名权 |
| 麻子柒 | 揭棋盘之死 | 想被记得，死在空驿，促成真名运动 |

---

## 5. 明暗线

- **明线**：守驿 → 追空驿真相 → 改商号屈辱 → 民谣抗册  
- **暗线**：路耗制、私盐假哨、并驿删人  

交汇：真名一旦只存在于官册，人就可以被合法吃掉。

---

## 6. 节奏曲线

```
苦守与义气 → 误哨死人 → 发现抹名制度 → 签合同的屈辱 → 假哨大骗 → 唱词夺权（悲壮余烬）
```
