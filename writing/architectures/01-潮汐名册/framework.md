# 《潮汐名册》整体故事框架

> 读这一份就能把握全书骨架。人物细卡见 `characters/`，势力见 `factions/`。

---

## 1. 故事是什么

东海边城「浦汐」。周氏三代守泵房，靠一台时准时不准的潮汐预测仪「听潮匣」活命。  
保险公司与市政排水局把洪水写成可交易的「可淹区」。周家越守，越发现：不是潮水要淹他们，是名册先判定他们该被淹。

**不是**：天才工程师修好大坝救全城。  
**而是**：治水共同体在「合法淹没」制度里代际求存；好运会失灵。

---

## 2. 核心引擎（六根柱）

| 柱 | 内容 |
|---|---|
| 鉴（受限好运） | 听潮匣：能报 72 小时淹没概率；传感器被关/腐蚀就会空报或漏报 |
| 压力机 | 可淹区收储 + 保费分区 + 临时工堵最险口子 |
| 共同体 | 周氏泵房（家规：先报民口、瞒报开革） |
| 揭棋盘之死 | 外姓工阿蟳死于「仪报安全」之夜 → 发现市政关停外侧传感器 |
| 制度过时 | 家规敌不过《临时淹没补偿条例》；后被迫改「测报订阅」 |
| 终局形态 | **半成功**：老街仍部分被淹，但「致盲日志」公开，名册合法性崩一角 |

---

## 3. 四卷故事线（主框架）

```
卷一 求生          卷二 揭棋盘         卷三 制度升级        卷四 抗命数
守泵/台风/家人化 → 阿蟳之死打开上层 → 预警商品化/家规裂 → 算法判淹 vs 走私真数据
```

### 卷一 · 求生（读者先爱人）

1. 仪报中风险，官报可控；周衡按家规先撤民口。  
2. 沙袋、柴油、人情债；外姓阿蟳申请编制失败仍留下。  
3. 周晚潮学测报，开始记录「仪与眼不一致」。  
4. **卷末**：仪报安全夜 → 阿蟳被浪抽出泵房而死 → 晚潮偷到关停日志。  
5. **好运失灵**：匣当晚未报警——不是神失灵，是网被人为致盲。

### 卷二 · 揭棋盘（读者看见吃人规则）

1. 阿蟳进「自然灾害损耗」，不进工伤。  
2. 保险精算把老街标成可淹资产；补偿表对接地产收储。  
3. 周衡停职；晚潮被调宣传岗。  
4. 明线从「守堤」变成「追谁关了传感器」。

### 卷三 · 制度升级（旧规矩不够用）

1. 周氏改民办测报社，靠卖预警订阅续命。  
2. 买得起预警的人先跑；穷人仍是堤。  
3. 周衡把加密真数据拆成给穷人的免费短讯——违新合同。  
4. **大失灵**：匣连报三天低风险，周衡押上沙袋库存，潮头改道砸老街。

### 卷四 · 抗命数（与「已被算死」对撞）

1. 算法结局：老街应淹、周氏应迁、测报应国营收编。  
2. 变数：晚潮公开匣的失灵/致盲日志，证明官府主动致盲。  
3. 结局：半成功——水仍来，但「可淹」不再理所当然。

## 4. 人物在框架里的位置

| 人物 | 框架职能 | 弧线一句话 |
|---|---|---|
| 周衡 | 家规活体 / 决策者 | 从「测错自负」到为真数据付代价 |
| 周晚潮 | 视角锚 / 鉴的翻译者 | 从信数据到把失灵变成证据 |
| 阿蟳 | 揭棋盘之死 | 想进名册「人」栏，死后仍是「损耗」 |

每卷主焦点 ≤ 3 人；其他人当制度零件。

---

## 5. 明线 / 暗线怎么缠

- **明线**：守泵求生 → 追责致盲 → 测报商品化 → 公开日志  
- **暗线1**：淹没补偿条例 = 低价收储工具  
- **暗线2**：传感器「维护」= 人为致盲  
- **暗线3**：听潮匣神迹 = 未被完全收编的传感器网  

交汇规则：每卷至少一次，真数据流到「不该看到的人」手里。

---

## 6. 情绪与节奏曲线

```
信任仪器/家规
    ↓
第一次救人成功（升温）
    ↓
安全夜死人（断裂）
    ↓
发现被算计（愤怒+寒意）
    ↓
制度升级仍吃人（绝望的清醒）
    ↓
公开致盲、半成功（悲壮的余烬）
```

## 7. 开写入口（最小下一动作）

从卷一第一节写：**台风前夜，周衡摸匣测温，官讯与家规打架**。  
不要先写保险阴谋坦白；阴谋只通过配额、工单、名册字段露齿。
