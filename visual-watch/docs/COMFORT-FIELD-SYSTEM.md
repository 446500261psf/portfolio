# 舒适区动态场系统（Comfort Field System）

> Cove Watch 核心表达引擎 · 技术-设计规格 v1.0  
> 本文档是 PRD v2.0 第 7–8 章的展开说明，供设计、固件、渲染工程共用。

---

## 0. 设计立场

传统可穿戴用**离散符号**（图标、文字、几何形）回答「现在几点、有什么事」。

Cove Watch 回答另一个问题：

> **「此刻，我的身体与心理是否处于合适的状态？若否，正在向何处漂移？」**

表达手段不是符号，而是**持续演化的场**——色彩、粒子、流向、呼吸节律——在一个鹅软石般的 2.5D 凹面中流动。用户通过**具身直觉**（embodied intuition）阅读表盘，而非解码图标。

理论锚点（非用户可见，但指导设计决策）：

| 框架 | 用途 |
|------|------|
| Russell 情感环状模型 | Valence × Arousal 二维舒适区坐标 |
| 具身认知（Embodied Cognition） | 形态即交互；鹅软石触感降低防御性 |
| 神经觉理论（Polyvagal, 轻量映射） | 安全/激活/退缩三态 → 三种场态原型 |
| 超日节律（Ultradian） | 90min 块的自然过渡曲线 |
| 日本「間」与枯山水 | 留白、粒子即沙纹；边缘即岸 |

## 1. 人机交互基座：鹅软石 2.5D 界面

### 1.1 为何形态是第一交互层

交互顺序不是「看屏幕 → 读信息 → 行动」，而是：

```
触/握（可选） → 抬腕 → 余光浸入 → 身体对齐 → 自然过渡
     ↑                                              ↓
  鹅软石形态                                   无需命名状态
  2.5D 凹面景深                              即可感受「该不该换态」
```

表盘不是贴在手上的**屏幕**，而是嵌在腕上的**小潭**——光与粒子在潭中发生，边缘微微隆起，像被河水磨过的石头。

### 1.2 形态规格

| 属性 | 规格 | 设计意图 |
|------|------|----------|
| 外轮廓 | 超椭圆（Superellipse），n≈4–5 | 介于方与圆之间；无尖角，无正圆的几何冷感 |
| 长宽比 | 约 1.15 : 1（近椭圆） | 顺腕弧；比正圆更「有机」 |
| 外轮廓 R角 | R45–R52（相对 44mm 宽度） | 大圆角；握持无压力点 |
| 屏幕开窗 | 内缩超椭圆，距外壳 1.2mm 唇边 | 形成「岸」与「潭」的分界 |
| 2.5D 深度 | 边缘高 0.4–0.8mm，中心凹 0.1mm 光学模拟 | 物理微弧 + 光学透镜叠层 |
| 玻璃 | 2.5D 热弯 Gorilla Glass，内表面 AR + 边缘增亮膜 | 边缘 catch light，强化潭口感 |
| 中框 | 雾面陶瓷 / 细磨砂钛 | 温差友好；低反光 |

### 1.3 2.5D 光学栈（Cross-section）

```
        环境光
           ↓
    ┌──────────────┐  ← 唇边高光（2.5D 物理隆起）
    │╲  弧面玻璃  ╱│
    │  ╲________╱  │
    │   偏光/AR    │
    │   AMOLED     │  ← 有效显示区：超椭圆 mask
    │   黑色基板   │     粒子永不贴边；始终有「岸内」余量
    └──────────────┘
           ↑
      暗色 FPC 过渡 → 屏周 ≈ 深潭壁（UI 不可绘入）
```

**渲染约束**：所有粒子、色场必须在「潭心安全区」内活动；距 mask 边缘 ≥8% 屏宽。过渡态时粒子可**向边缘汇聚**（暗示「即将漫溢/切换」），但不越过岸线。

### 1.4 触觉交互（MVP → v1.1）

| 输入 | MVP | v1.1+ |
|------|-----|-------|
| 抬腕 | 亮潭 + 场加速 200ms 后归稳 | 同左 |
| 侧键短按 | 预览下一舒适区场 | 同左 |
| 侧键长按 | 配对 | 同左 |
| 触摸潭面 | 不支持 | **轻触 = 身体签到（Body Check-in）**：场短暂收束后展开，记录主观舒适度 |

## 2. 舒适区模型（Comfort Zone Model, CZM）

### 2.1 三维坐标

每个日程块映射到 CZM 空间中的一个**目标点 P** 与**过渡曲线 Γ**：

| 轴 | 符号 | 范围 | 含义 |
|----|------|------|------|
| **激活度** | A (Activation) | 0–1 | 身体唤醒：0=静息，1=高动量 |
| **开放度** | O (Openness) | 0–1 | 心理-social：0=内收专注，1=外放联结 |
| **稳定度** | S (Stability) | 0–1 | 节奏可预测性：0=自由漂移，1=高度结构化 |

MVP 用 **A × O** 平面为主，S 影响**粒子相干度**（coherence）。

### 2.2 预设舒适区原型（非图标，是「场态」）

| 原型 | A | O | S | 身体感受 | 心理感受 |
|------|---|---|---|----------|----------|
| **深潭** Deep Pool | 0.25 | 0.15 | 0.85 | 坐定、低温、呼吸慢 | 内省、单人创造 |
| **暖流** Warm Current | 0.45 | 0.70 | 0.60 | 轻度社交能量 | 对话、协作、共情 |
| **跃泉** Upwelling | 0.80 | 0.40 | 0.50 | 肌肉预备、心率升 | 运动、行走、释放 |
| **静岸** Still Shore | 0.10 | 0.30 | 0.90 | 躺/卧、副交感 | 睡眠、冥想、发呆 |
| **紊流** Crossflow | 0.55 | 0.55 | 0.20 | 多任务切换 | 杂务、通勤、缓冲 |
| **空潭** Open Basin | 0.20 | 0.50 | 0.10 | 无安排 | 自由、未定义 |

用户可在 App 用**身体语言**微调（见 4.2），而非选「三角形」。

### 2.3 日程 = 在 CZM 中的轨迹

一天是一条分段曲线 γ(t)：

```
07:00 ──静岸──► 09:00 ──深潭──► 12:00 ──暖流──► 13:00 ──静岸──► ...
         │              │              │
      粒子极少      定向层流        暖色涡旋
      冷灰绿          钴蓝            琥珀
```

**Transition（切换窗）** 不是弹通知，而是 γ(t) 在 5–15min 内**平滑插值**到下一目标点，场态连续变形。

## 3. 动态视觉参数（场 → 像素）

表达**不用几何图元**（禁止多边形、箭头、icon）。唯一允许的基础元素：

- 全屏/局部 **色场 gradient mesh**（4–16 控制点）
- **粒子系统**（500–3000 虚拟粒子，实际渲染 80–400 可见）
- **流向场** vector field（Perlin / Curl noise）
- **2.5D 边缘光** rim luminance（非几何，是光晕）
- **呼吸调制** global breath envelope

### 3.1 参数映射表

| CZM 维度 | 色彩 | 粒子 | 流向 | 边缘光 |
|----------|------|------|------|--------|
| A ↑ | 饱和度↑、色温→中性偏冷 | 速度↑、size↓、trail↑ | 方向性↑、涡度↑ | 脉动频率↑ |
| O ↑ | 色温→暖、Hue 向橙/金 | 粒子数↑、orbit 行为 | 向外扩散 bias | 边缘光更宽 |
| S ↑ | 对比度↓、渐变更缓 | coherence↑（ flocking ） | 噪声↓ | 几乎静态 |
| S ↓ | 色相微漂移 | 布朗运动↑ | 随机↑ | 偶发闪沿 |

### 3.2 六原型 × 视觉签名（设计 north star）

#### 深潭 Deep Pool
- 色：#1a3a4a → #2d5a6b 径向，中心略亮
- 粒子：80 粒，慢速 inward drift，长拖尾 2s
- 流向：中心微弱吸纳
- 呼吸：6bpm，透明度 ±8%
- **一眼感受**：「可以沉下去做事」

#### 暖流 Warm Current
- 色：#c4783a → #e8b88a 水平缓变
- 粒子：200 粒，orbit 椭圆路径，互斥避免 clump
- 流向：顺时针慢涡
- **一眼感受**：「有人在场、可以说话」

#### 跃泉 Upwelling
- 色：#3d8b7a → #7ecdb8 自下向上
- 粒子：300 粒，upward bias + 高 velocity
- 流向：底部 spawn，顶部 dissipate
- **一眼感受**：「身体该动起来」

#### 静岸 Still Shore
- 色：#1e2d24 → #2a3d32 极低对比
- 粒子：≤30 粒，几乎静止，偶发微漂
- 流向：近零
- 呼吸：5bpm，全屏亮度 ±5%
- **一眼感受**：「可以什么都不做」

#### 紊流 Crossflow
- 色：双 hue 缓慢交替（45s 周期）
- 粒子：180 粒，低 coherence，cross vector
- **一眼感受**：「在切换中，别深度投入」

#### 空潭 Open Basin
- 色：中性 #2a2a2e，极淡噪声
- 粒子：随机偶发
- **一眼感受**：「没有安排，自由」

### 3.3 四态生命周期（场态时相）

| 时相 | 时间条件 | 场行为 |
|------|----------|--------|
| **Dwelling** 驻留 | 块内稳态区（开始+10% ～ 结束-10%） | 目标点 P 稳定，仅 breath 微动 |
| **Approach** 趋近 | 下一块开始前 15min | 当前场向 P_next 色相漂移 20%；边缘粒子预汇聚 |
| **Crossing** 渡越 | 块切换前 5min ～ 后 3min | A/O 沿 Γ 插值；双 hue 混合；粒子行为 morph |
| **Drift** 漂游 | 无日程 | Open Basin 默认；若用户设「偏好静岸」则偏静 |

### 3.4 禁止项

- ❌ 多边形、线段图标、数字时钟（MVP）
- ❌ 高对比闪烁、>1Hz strobe
- ❌ 写实 emoji / pictogram
- ❌ 粒子贴边（破坏潭口隐喻）
- ❌ 突然硬切（≥500ms 参数突变，除亮屏 wake）

## 4. App 侧：舒适区编辑

### 4.1 「身体语言」编辑器（替代形状选择器）

用户调整三个滑杆 + 可选色温偏好：

```
激活度  ○───────────●  静 ←→ 动
开放度  ○─────●──────  内 ←→ 外
稳定度  ○────────●───  自由 ←→ 规律
色温    冷 ○────●──── 暖
```

实时预览潭面场态；保存为 `ComfortProfile`。

### 4.2 日程块绑定

```typescript
interface ComfortProfile {
  id: string
  name: string              // App 内「上午写作」
  czm: { a: number; o: number; s: number }
  colorBias?: { hue: number; warmth: number }
  preset?: 'deep_pool' | 'warm_current' | 'upwelling' | 'still_shore' | 'crossflow' | 'open_basin'
}
```

### 4.3 Onboarding 重设计

1. **握一块石头**（动画）：形态介绍，无文字表盘
2. **身体校准**：「此刻你更像静还是动？」→ 滑杆 → 看场变
3. **选一条今日轨迹模板** → 配对

学习曲线：不是记符号，而是**对齐个人对颜色/运动的联想**（2–3 天）。

## 5. 渲染引擎 `cove-field`

### 5.1 架构

```
Schedule + ComfortProfiles + timestamp
              ↓
      CZM Trajectory Resolver  →  P(t), Γ(t)
              ↓
      Field Parameter Lerp       →  FieldParams
              ↓
   ┌──────────┴──────────┐
   │ Gradient Mesh       │
   │ Particle Sim (CPU)  │  ← 固定 tick 30Hz
   │ Rim Shader          │
   │ Breath Envelope     │
   └──────────┬──────────┘
              ↓
      Superellipse mask + 2.5D vignette
              ↓
         Framebuffer → AMOLED
```

### 5.2 性能预算（手表）

| 项 | 目标 |
|----|------|
| 帧率 | 30fps 活跃 / 1fps 低功耗 ambient |
| 粒子 | ≤400 rendered |
| 功耗 | 活跃渲染 <40mW 增量 |
| 内存 | Field engine <256KB RAM |

### 5.3 共享内核

TypeScript（App 预览）与 C（固件）共享：

- 同一 `FieldParams` 结构
- 同一 CZM 插值算法
- Golden snapshot 测试：给定 t + schedule → 固定 seed 粒子图 hash

## 6. 验证方法

### 6.1 定性

- **3 秒感受测试**：展示场 3s 后问「你现在更想动还是静？」→ 与 CZM 目标 A 轴对比
- **混淆矩阵**：六原型互认率 ≥75%

### 6.2 定量

- 抬腕后 5s 内 HR 变异性不升高（相对 push 通知基线）—— 需内测生物反馈 optional
- 14 日留存、日均抬腕次数（见 PRD §18）
