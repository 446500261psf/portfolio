本目录收集两个设计主题相关的权威色彩研究、标准与用户原声。

- 中文总览：`summaries/00-总览与关键发现.md`
- 主题1小结：`summaries/01-健康卫生安全-文献小结.md`
- 主题2小结：`summaries/02-运动-文献小结.md`
- 跨领域与原声：`summaries/03-跨领域与用户原声.md`

## 证据使用建议
安全场景优先遵循 ISO 3864 / ANSI Z535；医疗与运动心理结论多为倾向性证据，落地前建议做目标用户测试。
