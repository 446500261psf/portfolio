## 一句话结论

- **健康 / 卫生安全**：证据最稳的是「冷色（蓝绿）偏放松 / 白偏洁净感知 / 安全色有国际标准」；但把某一墙色直接等同于治愈力，学术上仍偏弱。
- **运动**：红色与竞争优势、黑色与攻击性感知是经典议题；近年综述与元分析认为**对真实胜负的因果证据偏弱**，但**感知与动机层**影响仍常被引用与应用。

---

## 两个主题的色彩语义地图

| 色系 | 主题1：健康 / 卫生 / 安全 | 主题2：运动 / 竞技 |
|------|---------------------------|-------------------|
| 白 | 洁净、无菌、医疗信任；过度使用易显冰冷、机构感 | 裁判/中性；轻量、透气运动服常见 |
| 蓝 | 平静、信任、卫生包装第二高频 | 冷静、耐力、专注；部分研究称降低心率 |
| 绿 | 自然、愈合、手术室传统联想；术后情绪较优 | 安全/通过；户外与恢复类运动 |
| 黄 | 警示（ISO/ANSI 安全色）；儿科可适度明亮 | 乐观、高可见；过强可能疲劳 |
| 红 | 禁止/消防/危险；伤口环境慎用 | 支配、唤醒、竞赛优势假说 |
| 橙 | ANSI Warning；康复激励可点缀 | 能量、HIIT、热情 |
| 黑 | 少用于疗愈主色 | 攻击性/力量感知；时尚运动主流 |
| 灰 | 中性背景；术后研究中表现偏弱 | 器材/工业运动空间 |

## 跨领域应用速览

| 领域 | 健康 / 卫生安全 | 运动 |
|------|-----------------|------|
| 时尚 / 服饰 | 康复服、医用感白蓝；色彩治疗辅助心理舒适 | Activewear：红橙冲刺、蓝绿耐力、黑力量 |
| 产品设计 | 卫生产品白+蓝；安全标签遵循 ISO/ANSI | 球衣、器材、可穿戴；品牌红黑高冲击 |
| 家具 / 室内 | 疗愈环境：蓝绿中性 + 自然材质 | 健身空间：红点缀 + 大面积冷静色 |
| 建筑 | 医院、诊所、创伤知情设计；避免大面积高饱和暖色 | 场馆、跑道、导视与安全色并用 |

## 证据层级提醒（使用时注意）

1. **强标准证据**：ISO 3864、ANSI Z535 安全色——属于规范，不是心理学实验。  
2. **中等学术证据**：医疗环境系统综述、运动服色批判性综述 / 元分析——结论多为「有方向但异质、需谨慎」。  
3. **经典但可争议**：Hill & Barton（红赢）、Frank & Gilovich（黑更侵略）——影响大，后续复制不完全一致。  
4. **行业 / 用户原声**：健身房杂志、医院设计博客、服饰媒体——适合洞察偏好，不宜当因果证明。
