# 主题1：健康 · 卫生 · 安全 —— 文献与标准小结

## 1. 医疗环境中的色彩（学术）

### 1.1 CHER / Tofle 等《Color in Healthcare Environments》（权威综述报告）
- **文件：** `01-health-hygiene-safety/CHER-color-in-healthcare-environments.pdf`
- **要点：** 回顾 3000+ 文献引用，目的是区分医疗色彩应用中的「迷思」与「实证」。
- **结论：** **没有可靠、可预测的单一理论**说明某种墙色一定改善患者行为或疗效；既有知识碎片化、偶有冲突，多依赖轶事。
- **设计启示：** 色板应考虑地理、文化、年龄、活动类型、光源与空间尺度，而非套用「绿=治愈」口号。

### 1.2 Schwarz《Color Design in Healthcare Environments: Theoretical Observations》（EDRA）
- **文件：** `EDRA36-Schwarz-color-design-healthcare.pdf`
- **要点：** 呼应 CHER：现行医疗色彩指南证据不足；空间不会仅因指定颜色就变成「放松」或「沉思」。
- **设计启示：** 先弄清色彩「被期望做什么」，再验证，而不是先上规范色再事后找理由。

### 1.3 SEMJ 系统综述《The Impact of Color in Healthcare Environments》(2024)
- **文件：** `SEMJ-146676-color-healthcare-systematic-review.pdf`
- **要点：** PRISMA 系统综述；纳入研究少，但综合方向为：冷色（尤其蓝绿）多与放松、减压、较佳体验相关；文化差异与光照需纳入。
- **设计启示：** 可用作「倾向性证据」，仍建议与本地用户测试结合。

### 1.4 术后病房墙色比较研究（2024–2025，Rappang Hospital）
- **文件：** `ANPC-12-169-hospital-wall-colors-recovery.pdf`
- **方法：** 300 名术后患者随机分到白 / 绿 / 蓝 / 黄 / 粉 / 灰房间；HADS + 住院时长 + 疼痛。
- **结果：** **绿、蓝**组情绪改善与恢复指标显著优于灰、白；黄、粉中等。
- **注意：** 单中心、准实验；机制叙述（内啡肽等）需审慎解读，但方向与主流设计实践一致。

## 2. 安全色标准（规范层，权威性最高）

### 2.1 ISO 3864（安全标识与安全色）
- **本地摘录：** `ISO-3864-Wikipedia.html`（维基对标准的公开摘要；正式标准需 ISO 购买）
- **核心语义：**
  | 含义 | 典型色 | 形状线索 |
  |------|--------|----------|
  | 禁止 / 消防 | 红 | 圆 + 斜杠 / 消防设备 |
  | 警告 | 黄 | 三角 |
  | 强制 | 蓝 | 圆 |
  | 安全状态 / 急救 | 绿 | 方/矩形 |
  | 对比 | 白 / 黑 | 提高可读性 |

- **近似色值参考（公开 RAL 对照，非正式色度测量）：**  
  Signal Yellow ≈ `#F9A900` · Signal Red ≈ `#9B2423` · Signal Blue ≈ `#005387` · Signal Green ≈ `#237F52`

### 2.2 ANSI Z535.1-2022 Safety Colors
- **说明存档：** `summaries/refs-ANSI-Z535.md`（因站点 Cloudflare 拦截，正文由权威博客摘录）
- **要点：** 规定北美安全色体系，并与 ISO 3864-4 协调；用 Munsell / CIE 色度界定，而非随便选「差不多的黄」。
- **ANSI 特有：** Yellow = Caution；Orange = Warning（比黄更严重）；Blue = Notice / Mandatory；Green = Safety instruction。

### 2.3 产品与环境应用
- 产品安全标签 → ISO 3864-2  
- 场所标识、围栏胶带、临时警示 → ANSI Z535.2 / .5  
- **设计原则：** 安全色服务「快速可识别」，不是品牌装饰；品牌色不得淹没安全语义。

## 3. 卫生 / 洁净感知（产品与包装）

### 3.1 食品包装色彩与选择（BJFT 2023）
- **文件：** `BJFT-2023-impact-of-color-packaging.pdf`
- **要点：** 乳制品包装中 **白最常见（纯净、卫生）**，**蓝第二（平静、可靠、卫生）**；蓝常用于传达高附加值与可信度。

### 3.2 女性卫生用品白色偏好（HHS 硕士论文）
- **文件：** `HHS-unbleached-sanitary-pads-color-perception.pdf`
- **要点：** 漂白白色与「干净、女性化、卫生」强绑定；未漂白本色产品需克服「不够干净」的感知障碍。
- **用户原声意义：** 洁净 ≠ 真实清洁度，而是**文化习得的色彩期待**。

### 3.3 行业文：卫生产品色彩心理学（Fresh Products）
- **文件：** `FreshProducts-color-hygiene.html`
- **要点：** 蓝→干净、冷静、信任；白→纯净无菌；色彩还影响对气味的预期（绿偏草本等）。

## 4. 推荐色板（综合研究后的设计参考，非处方）

| Token | Hex | 用途建议 |
|-------|-----|----------|
| Clinical White | `#F7F8F5` | 诊疗、包装、洁净面 |
| Soft Mint | `#C8DDD0` | 病房辅助、等候 |
| Healing Sage | `#6FA08A` | 恢复区、自然联想 |
| Calm Blue | `#5B8FA8` | 信任、卫生、平静 |
| Trust Navy | `#2F4F6B` | 专业、器械、信息 |
| Safety Yellow | `#F2B705` | 警示、导视（标准对齐） |
| Alert Red | `#C0392B` | 禁止/紧急（标准对齐） |

**慎用：** 大面积高饱和红橙（创伤知情设计指出易过度刺激）；纯白铺满（用户常感冰冷、机构化）。
